# Manufacturing Anomaly Detection

A self-contained anomaly detection study on synthetic manufacturing telemetry. It compares a scikit-learn MLP reconstruction model with Isolation Forest, uses chronological partitions, and exposes batch and HTTP scoring. This is an independent learning project, with no employer data or affiliation.

## Run locally

Use Python 3.12+ in a fresh environment.

```sh
python -m venv .venv
# Activate the environment, then:
python -m pip install -e .
python -m unittest discover -s tests -v
python -m crowe_anomaly.train
python -m crowe_anomaly.service --host 127.0.0.1 --port 8000
```

See `docs/ORIGINAL_README.md` for batch scoring and container commands.
